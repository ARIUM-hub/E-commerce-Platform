# 袜子商城多语言支持设计文档

- 日期：2026-07-17
- 主题：为 `socks-product-list.html` 增加中英文双语切换
- 范围：列表页、详情页、购物车抽屉、订单页、来源提示与推荐区

## 1. 目标

让当前袜子商城从“中英混合文案”升级为真正可切换的双语界面：

- 支持 `中文` 与 `English`
- 切换后立即刷新当前页面可见文案
- 页面跳转后仍保持用户选中的语言
- 不破坏现有列表、详情、购物车、订单、breadcrumb 跳转逻辑

## 2. 本期范围

本期包含：

- 全局语言状态
- 页面顶部语言切换控件
- 主要可见 UI 文案翻译
- 商品标题、描述、分类、购物车明细等前端展示翻译
- 购物车抽屉、订单页、breadcrumb、来源提示翻译

本期不包含：

- 新增第三种语言
- 后端返回多语言字段
- URL 级语言参数
- 自动按浏览器语言切换

## 3. 设计方向

采用“前端本地化层”方案：

- 默认语言：`zh-CN`
- 可切换语言：`en-US`
- 语言偏好存入 `localStorage`
- 页面跳转不追加 `lang` 参数
- 保持现有导航 URL 结构不变，避免影响严格 URL 测试

## 4. 交互设计

### 4.1 语言切换位置

在页面顶部增加轻量语言切换器：

- `中文`
- `English`

要求：

- 当前语言高亮
- 在 storefront / detail / order 三种视图都可见
- 不抢主视觉层级，保持黑白灰简约风格

### 4.2 切换行为

- 点击语言按钮后立即更新当前视图文本
- 不刷新整页
- 当前购物车状态、筛选状态、页面视图保持不变
- 后续页面跳转沿用已选语言

## 5. 文案本地化范围

### 5.1 全局 UI 文案

包括但不限于：

- 页面标题
- hero 标题与描述
- 分类 / 排序 / 购物车
- 结果数量
- 空状态
- 加入购物车 / 已加入购物车
- 查看详情 / 查看商品
- 清空购物车 / 关闭购物车
- 订单页与确认态按钮

### 5.2 详情页文案

包括：

- breadcrumb
- `Back to results for ...`
- `当前排序：...`
- 推荐区标题
- Continue Browsing 标题
- 缺失商品空状态

### 5.3 订单页文案

包括：

- Order confirmed / Order summary
- Continue shopping 来源说明
- 默认来源说明
- 推荐区标题
- 空订单提示

### 5.4 商品内容翻译

本期前端维护英文映射：

- 商品标题
- 商品描述
- 分类标签
- 购物车项标题

商品基础数字信息保持不变：

- 价格
- 折扣数值
- 尺码
- 评分数值

## 6. 数据策略

继续复用现有 `/api/products` 与 `/api/cart` 数据结构。

由于后端当前只返回单份商品文案，本期在前端补一层本地化映射：

- 以 `product.id` 为键
- 输出对应英文标题与描述
- 其余通用字段通过字典函数翻译

这样可以做到：

- 不改接口
- 不改数据文件结构
- 快速落地真实语言切换

## 7. 状态设计

新增前端语言状态：

- `activeLocale`

持久化：

- `localStorage`

规则：

- 初次进入默认 `zh-CN`
- 若本地已有偏好，则优先读取本地偏好
- 切换后重新渲染当前视图

## 8. 技术设计

建议新增：

- locale 常量
- 通用翻译字典 `translations`
- 商品英文映射 `localizedProductContent`
- `t(key, params)` 翻译函数
- `getLocalizedProduct(product)` 数据投影函数

渲染策略：

- 所有模板函数尽量从翻译函数拿文案
- 所有商品展示优先使用 `getLocalizedProduct(product)`

## 9. 回退策略

- 如果某个翻译 key 缺失，回退中文或原始值
- 如果某个商品英文映射缺失，回退原始商品数据
- 如果本地存储内容异常，回退 `zh-CN`

## 10. 测试范围

需要新增回归测试：

- 默认中文文案正常显示
- 切换到英文后 storefront 文案更新
- 英文状态下进入 detail 文案仍保持英文
- 英文状态下进入 order 文案仍保持英文
- 购物车与来源提示在英文下同步翻译

同时保证不回退：

- URL 跳转链路
- 购物车状态更新
- 订单确认页
- breadcrumb/source 文案功能

## 11. 验收标准

- 用户可以手动切换中英文
- 当前页面无需刷新即可完成语言更新
- 页面跳转后语言保持一致
- 主要可见 UI 与商品展示文案都有对应翻译
- 不新增后端接口
- 不破坏现有测试链路
