# Socks Seeded Reviews Design

## Goal

商品详情页默认展示多条真实风格示例评论，让评论区在用户未提交评论前也更像真实商城。

## Design

示例评论写入数据库初始化流程的 `product_reviews` 表，而不是硬编码在前端页面中。这样详情页、评论数量、评分摘要和评论接口都使用同一条真实数据流。

每个核心商品预置 3 条中文评论，覆盖短昵称、自然短评、4-5 星评分。初始化逻辑需要幂等：固定示例评论使用固定 ID 写入，服务重启时不会重复插入，也不会覆盖用户真实提交的评论。

## Testing

新增 API 测试验证初始化后 `GET /api/products/sock-02/reviews` 返回 3 条示例评论，并包含预期内容。同步更新详情页 UI 测试，确保默认评论、提交后评论数量和评分摘要都来自接口。
