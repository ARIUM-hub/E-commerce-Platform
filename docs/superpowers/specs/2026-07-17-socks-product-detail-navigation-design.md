# 袜子商品详情跳转设计文档

- 日期：2026-07-17
- 主题：为 `socks-product-list.html` 增加商品详情视图与页面跳转
- 方向：让商城从“可浏览列表”升级为“列表可进入详情”的真实电商浏览链路

## 1. 目标

在现有袜子商城基础上，补齐最核心的一段页面跳转：

- 商品列表页进入商品详情页
- 商品详情页返回商品列表页

同时保持当前已经存在的统一入口思路，不再新增独立详情 HTML 文件。

## 2. 范围

本次设计包含：

- 列表页商品卡详情入口
- 统一入口详情视图 `?view=detail&id=...`
- 详情页返回列表页
- 返回时保留来源筛选和排序参数
- 详情页商品不存在时的空状态

本次设计不包含：

- 新的后端商品详情接口
- 多级面包屑导航
- 多图轮播
- 商品评价详情区
- 推荐搭配详情模块

## 3. 设计方向

继续采用“单一入口多视图”方案：

- `socks-product-list.html` 保留为唯一主页面入口
- `?view=detail&id=sock-01` 用于显示商品详情
- `?view=order` 继续显示订单确认视图

这样可以保证：

- 页面体系统一
- URL 可直达
- 与已经并入统一入口的订单页一致

## 4. 页面结构

统一入口新增第三种视图：

1. Storefront view
   - 分类筛选
   - 排序栏
   - 商品列表
2. Detail view
   - 返回列表页按钮
   - 商品主视觉
   - 商品标题、价格、划线原价、折扣
   - 评分、评论数、配送、库存、热卖信息
   - 尺码选择
   - 加入购物车按钮
3. Order view
   - 现有订单确认内容

## 5. 跳转规则

### 列表页进入详情

每张商品卡增加一个详情入口，跳转到：

```text
/socks-product-list.html?view=detail&id=<productId>&filter=<activeFilter>&sort=<activeSort>
```

这样详情页知道：

- 当前查看的是哪个商品
- 这个商品是从什么筛选和排序状态进入的

### 详情页返回列表

详情页返回按钮跳回：

```text
/socks-product-list.html?filter=<sourceFilter>&sort=<sourceSort>
```

如果没有来源参数，则回到默认列表：

```text
/socks-product-list.html
```

## 6. 数据设计

详情页继续复用现有商品接口数据，不新增后端接口。

实现方式：

1. 请求当前已有的 `GET /api/products?filter=all&sort=recommended`
2. 在前端按 `id` 找到目标商品
3. 渲染详情视图

这样可以保证：

- 直达详情 URL 时仍能工作
- 与列表页商品源保持一致

## 7. 异常与空状态

当 `id` 不存在或商品加载失败时：

- 展示友好空状态
- 显示 `Product not found`
- 提供 `Back to storefront` 返回入口

不使用浏览器默认报错页。

## 8. 视觉规则

- 继续保持黑、白、灰主色
- 详情页仍沿用当前商品卡的材质和圆角语言
- 详情布局比列表页更宽松，强调单品浏览
- 返回按钮和主 CTA 视觉层级要清晰

## 9. 测试设计

需要补充：

- 列表页可以进入详情页
- 详情页能根据 URL 中的商品 `id` 正确渲染
- 详情页返回链接会保留原筛选和排序参数
- 无效商品 `id` 会显示友好空状态

## 10. 验收标准

- 从列表页可进入商品详情页
- 详情页 URL 使用统一入口 `socks-product-list.html?view=detail&id=...`
- 返回列表时能保留原筛选和排序状态
- 无效商品时显示友好空状态
- 不新增新的后端接口
