# Socks I18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add real bilingual support to `socks-product-list.html` so users can switch between Chinese and English without breaking current storefront, detail, cart, order, and breadcrumb flows.

**Architecture:** Keep the feature client-side. Store the selected locale in `localStorage`, translate UI strings through a shared dictionary, and project localized product copy on top of existing backend product payloads. Do not change URLs or backend APIs.

**Tech Stack:** Node.js HTTP server, HTML, CSS, vanilla JavaScript, Playwright

---

## File Structure

- Modify: `socks-product-list.html`
  Purpose: add locale state, UI toggle, translation helpers, localized product projection, and rerender logic.
- Modify: `tests/socks-product-list.spec.js`
  Purpose: verify locale switching, persistence, and translated source/order/detail states.

## Shared Rules

- Default locale is `zh-CN`.
- Supported locales are `zh-CN` and `en-US`.
- Locale state persists in `localStorage`, not the URL.
- Existing navigation URLs must remain unchanged.
- Missing translations must safely fall back to the original value.
